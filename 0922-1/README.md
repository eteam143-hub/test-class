# 小小大富翁

使用 Pygame 製作的玩家對電腦簡易大富翁遊戲。

## 執行方式

在本資料夾執行：

```bash
./play_monopoly.sh
```

或由專案根目錄執行：

```bash
uv run python 0922-1/monopoly_game.py
```

## 規則

- 玩家與電腦輪流擲骰，通過起點可獲得 $200。
- 停在無人持有的地產時，可以購買；停在對方地產時要付租金。
- 命運／機會格會隨機加減金錢；回到監獄格會暫停一回合。
- 任一方金錢小於零即破產，另一方獲勝。

# 經典接龍

使用 Pygame 製作的 Klondike（接龍）遊戲。

## 執行方式

在本資料夾執行：

```bash
./play_solitaire.sh
```

或由專案根目錄執行：

```bash
uv run python 0922-1/solitaire_game.py
```

## 操作與規則

- 按住一張正面牌，拖曳到目的地後放開滑鼠，即可移動；也可點選來源後再點選目的地。可一次移動合法的連續牌組。
- 連點兩下廢牌或遊戲區最上方的正面牌，若符合順序，會自動歸位到右上方相同花色的基礎牌堆。
- 遊戲區牌堆須以紅黑交錯、由 K 至 A 遞減排列；空欄僅能放 K。
- 左上角牌庫每次抽一張，抽完可回收廢牌堆。
- 右上角四個基礎牌堆須依同花色 A 至 K 遞增完成。
